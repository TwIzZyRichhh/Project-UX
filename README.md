# Project-UX

Projektin tarkoituksena on suunnitella Wolt-tyylinen robottitoimitussovellus, jossa asiakas
voi tilata ruokaa lähialueen ravintoloista ja saada tilauksen toimitettuna autonomisella
robotilla. Sovellus on suunnattu erityisesti henkilöille, jotka asuvat suhteellisen lähellä
ravintoloita, mutta eivät halua tai pysty käymään ravintolassa itse hakemassa tilausta.
Sovelluksen keskeinen ero tavalliseen ruoan kotiinkuljetukseen on se, että tilauksen
kuljetuksesta vastaa robotti ihmiskuljettajan sijaan. Tämä tekee palvelusta erityisen
sopivan lyhyille toimitusmatkoille, joilla robottitoimitus on käytännöllinen ja
kustannustehokas.
Yksi tärkeä kohderyhmä ovat etätyöntekijät. Etätöissä oleva henkilö voi esimerkiksi tilata
lounaan läheisestä ravintolasta poistumatta työpisteeltään. Ravintola valmistaa tilauksen,
jonka jälkeen robotti noutaa sen ja kuljettaa asiakkaalle.
